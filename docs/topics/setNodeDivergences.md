**setNodeDivergences** - *For each node in nodes list, store the divergence from the UCA*

Description
--------------------

For each node in nodes list, store the divergence from the UCA


Usage
--------------------
```
setNodeDivergences(tree)
```

Arguments
-------------------

tree
:   A `phylo` object with nodes list




Value
-------------------

`phylo` with node list and divergences set
