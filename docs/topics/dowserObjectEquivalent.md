Description
--------------------

`dowserObjectEquivalent`
Experimental. Check if two Dowser objects are equivalent


Usage
--------------------
```
dowserObjectEquivalent(
obj1,
obj2,
verbose = TRUE,
edge_tol = 1e-08,
dowser_fields = TRUE
)
```

Arguments
-------------------

obj1
:   First Dowser object

obj2
:   Second Dowser object

verbose
:   print out more info

edge_tol
:   tolerance for branch length checks (if check=TRUE)

dowser_fields
:   check dowser-specific fields and gapped sequences?
